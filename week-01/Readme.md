v## Week 01 - Cafe Expense Report

A Python program that reads cafe expenses from a JSON file
and generates a monthly expense report.

### Features
- Loads expenses from JSON
- Calculates total spending
- Groups expenses by category
- Identifies the largest expense
- Flags expenses requiring approval
- Saves a summary to JSON
- Handles missing and invalid JSON files

### How to run

python week-01/expenses.py
